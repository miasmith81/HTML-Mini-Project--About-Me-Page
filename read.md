# HTML Mini-Project – About Me Page

Recommended Time: ~2.5 hours

Phase: HTML – Building Web Foundations

Goal: Build a one-page HTML-only About Me site that demonstrates proper structure and semantic tags.

Learning Materials
Odin Project – Recipes / Mini-ProjectLinks to an external site.

Task
Open your Codespaces project.

Follow the Odin Project lesson to build a one-page About Me site using only HTML.

Commit and push your changes.

Submit your GitHub repo link in Canvas.

Reflection
Ask ChatGPT:

Can you review my page structure (headings hierarchy, sections) and identify one redundant or missing element?
Implement one suggested change and note it in your submission.
